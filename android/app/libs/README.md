# Avaya Android SDK Library Directory

Copy `oceanacustomerwebvoicevideo.aar` (Avaya WebRTC Connect SDK Release 4.0.10) into this directory before building with Gradle:

```text
android/app/libs/oceanacustomerwebvoicevideo.aar
```

`.aar` binaries are ignored by Git to avoid committing proprietary Avaya SDK redistributables.
