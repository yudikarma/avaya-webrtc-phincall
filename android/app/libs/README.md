# Avaya Android SDK Library Directory

Copy `oceanacustomerwebvoicevideo.aar` (Avaya WebRTC Connect SDK Release 4.0.10) into this directory before syncing or building in Android Studio:

```text
android/app/libs/oceanacustomerwebvoicevideo.aar
```

`.aar` binaries are ignored by Git to avoid committing proprietary Avaya SDK redistributables. For GitHub Actions CI/CD, see the CI/CD section in the root `README.md`.
